# Тестовое приложение

# Клонируйте проект командой: `git clone https://github.com/MaksLevchenko/Search_seals.git`

## Перейдите в корневую папку проекта командой: `cd Search_seals`

## Создайте виртуальное окружение командой: `python -m venv .venv`

## Активируйте виртуальное окружение командой: `.venv\Scripts\activate` для Windows, или: `source .venv/bin/activate` для Linux

## Установите необходимые библиотеки командой: `pip install -r requirements.txt`

## В папку photo копируйте фото в нерпами

## Запустите файл main.py командой: `python main.py` дождитесь окончания работы программыю В проекте появится файл result.txt
